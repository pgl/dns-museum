Type `/dig` in Discord and the bot asks for a domain name. By default it looks up IPv4 addresses. Choose MX instead and everyone in the channel can see the domain's mail servers.

Cloudflare's guide also documents a refresh button for repeating a lookup and a separate command for registration information.
