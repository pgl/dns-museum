DNS Messenger used a service called DNSKV as its shared message store. DNSKV associated a key with a value, so two copies of the messenger could exchange messages through the same store. The author described the resulting channels as obfuscated.

The source code is on GitHub. The original DNSMSG website did not respond when checked in November 2026.
